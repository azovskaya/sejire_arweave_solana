# SEJIRE — проверка перед переходом на другой Mac

Дата: 29 сентября 2026. Проверенная версия: `4725b1ec47c0a4129fdfa7a0835207377a35fccd`, ветка `feat/solana-preservation`.

## Итог

Бесплатная цепочка **программная подпись → реальный тестовый Turbo → квитанция → скачивание → восстановление** прошла снова. Восстановление свежей квитанции и реально скачанного зашифрованного файла прошло также в production-интерфейсе на двух отдельных origin браузера. Деньги не переводились; настоящие расширения Phantom/Solflare не проверены.

Все существующие автоматические тесты, TypeScript и сборка прошли. Найдено воспроизводимое ограничение мобильной кнопки «Вместить» и небольшие неточности текста. Обратный UI-импорт JSON остался непроверенным из-за зависания управления встроенным браузером. Аудит зависимостей не чистый; это не разрешение на mainnet.

## Найденные ограничения и незавершённые проверки

1. **Мобильное «Вместить» не вмещает всё дерево.** После восстановления тестового родителя/ребёнка при ширине 390 px нажать «Вместить»: левая карточка начинается на `x = -11.8 px`, часть имени обрезана. Причина подтверждена расчётом: world width 832 px, минимальный scale 0.55, смещение world -33.8 px. `apps/web/src/lib/pedigreeFit.ts` ограничивает масштаб снизу; тесты сейчас закрепляют это поведение. Нужно согласовать поведение Fit на узких экранах, а не считать отсутствие горизонтального скролла достаточным тестом. Данные не потеряны.
2. **Текст после импорта файла слов неточен.** При уже выбранном архиве подсказка говорит «Нажмите Открыть», но кнопка называется «Восстановить архив». Само восстановление прошло.
3. **Сообщение о неверном формате не перечисляет квитанцию.** Поле поддерживает архив/квитанцию/слова, а ошибка для `null` перечисляет только seed/envelope. Невалидный файл безопасно отклонён.
4. **Обратный импорт JSON через UI не подтверждён.** Экспорт и его содержимое проверены. При выборе файла для обратного импорта вызов браузерного управления завис; чтение состояния и закрытие тестовой вкладки тоже завершались тайм-аутом. В коде перед заменой существующего дерева вызывается `window.confirm`; связь с зависанием инструмента вероятна, но не доказана. В Chrome на другом Mac проверить вручную подтверждение/отмену импорта на вымышленных данных. Unit-тесты JSON прошли. После мобильного теста размер браузера сброшен.
5. **Зависимости требуют отдельного разбора.** Текущий production-only `npm audit --omit=dev`: web — 0 critical, 8 high, 6 moderate, 10 low; sponsor — 0. Это пакетные записи, включая транзитивные родительские цепочки, а не 24 доказанные уязвимости приложения. Достижимость из браузерного пути не установлена. `audit fix --force` и предложенные откаты SDK не выполнялись. Полный production-only отчёт: [audit snapshot](2026-09-29-web-production-audit.json).
6. Настоящие Phantom/Solflare, одобрение подписи в расширении, оплаченная devnet-загрузка и сверка реального платежа остаются непроверенными. Также не проверены mainnet, окончательное хранение, Safari/iOS/Android и реальная межвкладочная гонка расширений.

## Что делать на другом Mac

Открыть ветку `feat/solana-preservation`, прочитать `AGENTS.md` и `docs/CONTINUE_ON_ANOTHER_MAC.md`. Приложение запускать локально на том Mac и открывать именно в Chrome с установленным кошельком. Первым прогоном оставить пополнение выключенным. Подписи и любое разрешение на платёж выполняет владелец. Слова кошелька никогда не вводить в SEJIRE.

Следующий приоритет: расширение → бесплатная devnet-загрузка → скачать квитанцию и зашифрованный файл → восстановить в отдельном профиле. После этого отдельно проверить одобренный владельцем платный devnet-путь; не переходить на mainnet.
