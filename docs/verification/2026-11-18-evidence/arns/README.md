# Публичная запись ArNS: сохранённые доказательства

Эти файлы сохраняют три выполненных 18 ноября 2026 read-only RPC-запроса.
Сводка разделяет типизированное чтение Core owner, совпадения байтов и поля,
которые не были полностью декодированы. Владение пользовательским ключом
и возможность изменить имя не проверялись.

Два `*.raw.json` перенесены из точных JSON-строк завершённых tool outputs.
Третий `*.parsed-snapshot.json` — уже разобранный снимок stdout: `rentEpoch`
в нём округлён JavaScript Number и не используется для выводов; base64 account
bytes сохранены. Полные ограничения указаны в `rpc-captures.json` и `summary.json`.

Исходный `verify-saved-evidence.cjs`, `local-replay.json` и `SHA256SUMS` сохранены
без изменения как историческое свидетельство. `verify-saved-evidence-repo.cjs`
содержит те же проверки, с единственной поправкой пути к зависимостям репозитория.
Из корня установленного проекта выполните:

```sh
node docs/verification/2026-11-18-evidence/arns/verify-saved-evidence-repo.cjs
```

Для отдельной папки установленных проектных зависимостей задайте
`SEJIRE_PROJECT_ROOT` на корень этой копии. Replay читает только сохранённые
файлы и не вызывает сеть, кошелёк или транзакции. Его результат не обновляет
дату публичного наблюдения и не доказывает нынешнее владение именем.
