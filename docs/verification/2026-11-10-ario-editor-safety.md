# ar.io — этап 2A: сохранность локальных правок редактора

## Изолированный пакет

Родитель — пакет контролируемого выпуска Worker `ea70ea1a2ff65007850c7ef7126379a5a3afd54a`. Исходный Workspace соответствует blob `3b011aec95f6e6eeeca94610e40c10e4c5737c14`; локальная копия перед правкой проверена через git hash-object.

Изменён только прикладной компонент Workspace: отмена удаления теперь функционально восстанавливает одного человека в текущем дереве; callback привязан к исходному tree ID. Нельзя подставлять сохранённый после удаления полный снимок вместо актуального дерева.

Перед явными действиями (сменой карточки, уходом домой, сохранением, JSON/PDF экспортом, добавлением/удалением) профиль синхронно фиксируется через ограниченный event-only flushSync. Снимок для последующего действия берётся из актуального latestStore после обновления React. На каждое нажатие клавиши flushSync не вызывается. Ни формат архива, ни платёжный клиент/журнал, ни шифрование не меняются.

## Регрессионные сценарии

Добавлен отдельный Playwright config и семь тестов: undo после новых правок, переключение карточки до autosave, переход домой и reload, содержимое JSON, актуальный snapshot при сохранении с неизменностью прежних commits, отсутствие лишней ревизии без правок, данные для PDF exporter. Debounce 350 ms преднамеренно задерживается тестом; нет зависимости от скорости CI. PDF exporter в одном тесте заменён заглушкой для проверки переданного snapshot, PDF не генерируется.

Все данные синтетические. Внешние запросы блокируются; проверяется отсутствие внешних запросов, HTTP writes и JS ошибок. Кошелёк не подключается, заказ не создаётся, архив не загружается. Старые проверки CI сохранены, добавлен editor suite.

Локально: Node syntax и TypeScript/TSX transpile syntax — PASS. Полная типизация, реальные browser tests и полный CI должны подтверждаться отдельным новым GitHub run; локальный полный запуск не заявляется.

## Не входит в этот пакет

Межвкладочная защита, лимиты архива, серверные резервы, зависимости и перенос ArNS — отдельные этапы. Ни production, ни пользовательская папка на Mac не меняются созданием этого PR. До полного CI и проверки diff пакет не публиковать.
