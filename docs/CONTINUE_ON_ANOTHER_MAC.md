## Админка Preservation V2

В V2 `#/admin` ведёт в `AdminDesk` с одним переносимым административным паролем. Проверка использует публичный verifier `apps/web/public/admin-lock.json` (PBKDF2-SHA256, 600000 итераций), а не локальный `passwordHash`. В репозитории пока лежит отключённый placeholder. Владелец лично выполняет `npm run admin:set-password` в интерактивном терминале, затем этот verifier должен попасть в проверенную статическую сборку. Пароль не передаётся в CI, не сохраняется в browser storage; reload и выход требуют нового ввода. Старые локальные AES-GCM admin secrets расшифровываются тем же паролем, если он совпадает со старым. Диагностика V2 находится внутри защищённой админки. `#/restore` использует 12 слов только для пользовательского восстановления семейного сейфа; админский вход не читает mnemonic и не открывает vault. Проверка маршрутов и пароля: `npm run test:admin-browser --prefix apps/web`. Публикация root Pages и `/native-admin/` выполняется раздельно; нельзя считать изменение preview доказательством обновления корневого `#/admin`.
