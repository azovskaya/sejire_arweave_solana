# Flow 07 — Когда нужны 12 слов

## Новая последовательность (продукт)

1. **Открыть протокол** → сразу создать древо предков (без seed)
2. Проводник: **я → мама → папа → бабушки/дедушки**
3. Свободно дополнять род, фиксировать локальные версии
4. Кнопка **«Отправить в Arweave»** → только здесь:
   - создать/ввести 12 слов
   - зашифровать сейф
   - опубликовать / скачать envelope
5. Позже с другого устройства: «Открыть по 12 словам»

## Зачем так

Сбор семьи не должен упираться в крипто-онбординг.  
BIP-39 — ключ к **вечной публикации**, не к черновику.

Спека деривации: [`docs/security/SEED_ACCESS.md`](../security/SEED_ACCESS.md)

## Открыть уже сохранённое — без централизации

После того как сейф уже лежит в Arweave, **повторное открытие не требует** Kaspi, Stripe, Cloudflare и аккаунта SEJIRE.

1. Открыть приложение (канон: `sejire.ar.io`).
2. Ввести 12 слов.
3. Клиент считает `vaultId` + ключ шифрования.
4. Несколько независимых GraphQL/index источников, AR.IO peers и необязательные локальные/legacy подсказки дают возможные TX ID. Отказ одного сервиса не означает отсутствие сейфа.
5. Для каждого кандидата клиент получает metadata и `/raw/<txId>` через несколько gateway, проверяет размер, SHA-256, envelope и vault ID, затем расшифровывает локально и проверяет деревья. Поиск и скачивание не выполняют оплату или публикацию.
6. Из проверенных версий строится история `Parent-Tx`. Единственный HEAD открывается автоматически; при нескольких настоящих ветках пользователь может выбрать другую, и ни одна не удаляется.
7. Техническая диагностика без слов и семейных данных доступна только по `#/restore?diagnostics=1`. Подробности: [ADR 0009](../adr/0009-resilient-vault-recovery.md).
