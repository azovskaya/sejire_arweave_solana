Открыть архив без сервера

Выберите сохранённый зашифрованный JSON или recovery kit. Эта страница расшифровывает файл на вашем устройстве; доступ к сети не нужен.

Нужны 12 слов архива SEJIRE. Не вводите фразу платёжного кошелька. Квитанция без ciphertext не заменяет файл архива.

Скачать приватный JSON Результат содержит все данные и историю из выбранного архива без преобразований. Он не зашифрован. Проверка файла не подтверждает публикацию в блокчейне или полноту всех сетевых версий. Слова не сохраняются в браузерном хранилище; после работы закройте страницу.
